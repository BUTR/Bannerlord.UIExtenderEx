Namespace
Bannerlord.UIExtenderEx.ViewModels

Provides the base implementation for IViewModelMixin extending a target ViewModel.

Generic type parameter TViewModel designates the target host ViewModel type. Access the underlying host instance via the protected ViewModel property, which maintains a weak reference to avoid cyclic references and permit garbage collection. 

public abstract class BaseViewModelMixin<TViewModel> : IViewModelMixin where TViewModel : ViewModel

OnViewModelPropertyChanged(string)

Invoked whenever the attached host ViewModel raises any property change notification (including standard and typed overloads).

TaleWorlds ViewModels dispatch most property updates through typed OnPropertyChangedWithValue overloads that bypass standard PropertyChanged handlers. Overriding this method listens to all nine notification variants. Subscriptions are registered after host construction and detached when the host ViewModel is finalized.
