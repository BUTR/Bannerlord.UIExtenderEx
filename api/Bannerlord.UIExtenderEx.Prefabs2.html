Namespace Bannerlord.UIExtenderEx.Prefabs2

Classes

PrefabExtensionInsertPatch

Inserts content relative to the target node specified by XPath. A single property or method must be decorated with PrefabExtensionInsertPatch.PrefabExtensionContentAttribute.

Supported content attribute types:

  • PrefabExtensionInsertPatch.PrefabExtensionFileNameAttribute
  • PrefabExtensionInsertPatch.PrefabExtensionTextAttribute
  • PrefabExtensionInsertPatch.PrefabExtensionXmlNodeAttribute
  • PrefabExtensionInsertPatch.PrefabExtensionXmlNodesAttribute
PrefabExtensionInsertPatch.PrefabExtensionContentAttribute

Marks a single property or method in PrefabExtensionInsertPatch as providing the patch XML content.

Supported return types:

  • string: File name (with PrefabExtensionInsertPatch.PrefabExtensionFileNameAttribute) or raw XML markup (with PrefabExtensionInsertPatch.PrefabExtensionTextAttribute).
  • XmlNode or XmlDocument: Direct node/document insertion (with PrefabExtensionInsertPatch.PrefabExtensionXmlNodeAttribute).
  • IEnumerable<T> of XmlNode: Sequential node insertion (with PrefabExtensionInsertPatch.PrefabExtensionXmlNodesAttribute).
PrefabExtensionInsertPatch.PrefabExtensionFileNameAttribute

Specifies that the decorated member returns a file name located under the module's GUI folder.

PrefabExtensionInsertPatch.PrefabExtensionSingleContentAttribute

Base class for content attributes supplying a single root XML node.

PrefabExtensionInsertPatch.PrefabExtensionTextAttribute

Specifies that the decorated member returns raw XML markup string.

PrefabExtensionInsertPatch.PrefabExtensionXmlDocumentAttribute

Obsolete. Use PrefabExtensionInsertPatch.PrefabExtensionXmlNodeAttribute, which also accepts an XmlDocument.

PrefabExtensionInsertPatch.PrefabExtensionXmlNodeAttribute

Specifies that the decorated member returns an XmlNode or XmlDocument.

PrefabExtensionInsertPatch.PrefabExtensionXmlNodesAttribute

Specifies that the decorated member returns a collection of XmlNode instances inserted sequentially.

PrefabExtensionSetAttributePatch

Sets or updates XML attributes on the target node specified by XPath.
