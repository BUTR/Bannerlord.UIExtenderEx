Namespace Bannerlord.UIExtenderEx.Runtimes

Classes

MixinSource

Queries active and target ViewModel mixin types registered across all module runtimes, mirroring Gauntlet XML databinding resolution.

PrefabRuntimes

Coordinates registered prefab runtimes and exposes shared runtime capabilities.

When no runtimes are registered, all movies fall back to the native Gauntlet XML loader with all patches applied. Registered runtimes act strictly as performance optimizations, serving pre-compiled or dynamically compiled widget trees where applicable.

PrefabSource

Exposes patched prefab XML data, widget factory state, and lifecycle invalidation events consumed by prefab runtimes.

Events fire on the thread that triggered the underlying operation (typically the main engine UI thread, except when background compilation workers parse prefabs). Event handler exceptions are caught and logged without propagating into TaleWorlds engine calls.

RuntimeSettings

Provides access to prefab runtime settings persisted in the module's <Settings> declaration block within SubModule.xml.

ViewModelSource

Resolves property and command members against a live ViewModel instance's dynamic binding table, including attached mixin members.

Interfaces

IPrefabRuntime

Defines a movie loading strategy queried by UIExtenderEx prior to every UI movie load in GauntletMovie.Load.

Intended for runtime implementations rather than mod consumers. While mod extensions (prefab patches and ViewModel mixins) determine visual and logical structure across all runtimes, the active runtime controls execution strategy and performance without altering rendered content.
