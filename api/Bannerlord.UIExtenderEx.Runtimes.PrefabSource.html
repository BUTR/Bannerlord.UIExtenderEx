Class PrefabSource

Namespace
Bannerlord.UIExtenderEx.Runtimes
Assembly
Bannerlord.UIExtenderEx.dll

Exposes patched prefab XML data, widget factory state, and lifecycle invalidation events consumed by prefab runtimes.

Events fire on the thread that triggered the underlying operation (typically the main engine UI thread, except when background compilation workers parse prefabs). Event handler exceptions are caught and logged without propagating into TaleWorlds engine calls.
